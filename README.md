Not to be confused with a professional endeavor.

## What's here

Short Python scripts that follow a beginner's path through machine learning, one idea per file:

| # | Script | Topic |
|---|--------|-------|
| 1 | `1-understandingData.py` | Mean, median, mode, spread |
| 2 | `2-newDataset.py` | Random data and histograms |
| 3 | `3-normalDataDistribution.py` | Normal distribution |
| 4 | `4-scatterPlot.py` | Scatter plots |
| 5 | `5-linearRegression.py` | Linear regression |
| 6 | `6-polynomialRegression.py` | Polynomial regression |
| 7 | `7-multipleRegression.py` | Multiple regression |
| 8 | `8-scale.py` | Feature scaling |
| 9 | `9-trainTest.py` | Train/test split |
| 10 | `10-decisionTree.py` | Decision trees (drawn with Graphviz) |

`cardekho.py` applies these to a real used-car dataset (`cardekho.csv`). `cars.csv`, `cars2.csv` and `shows.csv` are the smaller practice datasets.

## Run

```bash
pip install numpy pandas matplotlib scipy scikit-learn pydotplus
python3 5-linearRegression.py
```
